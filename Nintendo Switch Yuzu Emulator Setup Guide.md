## 🔧 Установка

### Шаг 1: Скачайте и распакуйте

- Скачайте `Yuzu-Emulation-Software.zip` (~50 MB)
- Распакуйте с помощью WinRAR или 7-Zip. **Пароль не требуется.**

### Шаг 2: Добавьте ключи

- Откройте папку `/keys`
- Скопируйте туда `prod.keys`
- Не переименовывайте файл

### Шаг 3: Установите прошивку

- Откройте Yuzu
- Перейдите в **File → Install Firmware**
- Выберите ZIP-файл прошивки
- Дождитесь установки

### Шаг 4: Настройте графику

- Откройте **Emulation → Configure → Graphics**
- Выберите **Vulkan**
- Установите разрешение и лимит FPS

### Шаг 5: Добавьте игру и контроллер

- **File → Load File** → выберите NSP или XCI
- Подключите геймпад
- Настройте кнопки через **Emulation → Configure → Controls**
